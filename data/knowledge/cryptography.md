Cryptography is the practice of securing information through mathematical techniques so that only intended recipients can read it. The main types of cryptography are symmetric-key, asymmetric-key (public-key), and hash functions. Symmetric-key cryptography uses the same key for both encryption and decryption; AES (Advanced Encryption Standard) is the most widely used symmetric cipher today. Asymmetric cryptography uses a key pair — a public key for encryption and a private key for decryption — enabling secure communication without a shared secret; RSA and elliptic-curve cryptography (ECC) are leading examples. Hash functions transform arbitrary data into a fixed-size digest; SHA-256 is widely used in digital signatures and blockchain systems. Digital signatures use asymmetric cryptography to prove authenticity and integrity of a message. Transport Layer Security (TLS) combines asymmetric key exchange with symmetric encryption to secure web traffic (HTTPS). Cryptographic protocols like Diffie-Hellman key exchange allow two parties to establish a shared secret over an insecure channel. Post-quantum cryptography is an active research area aimed at algorithms resistant to attacks by quantum computers. Steganography is related but distinct — it hides the existence of a message rather than encrypting its content.
