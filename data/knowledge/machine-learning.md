Machine learning is a branch of artificial intelligence in which systems learn from data to improve their performance on tasks without being explicitly programmed. Instead of following hand-coded rules, a machine learning model finds patterns in training data and generalizes those patterns to new examples. Supervised learning trains on labeled examples — the model learns a mapping from inputs to outputs, as in image classification or spam detection. Unsupervised learning finds structure in unlabeled data through clustering or dimensionality reduction. Reinforcement learning trains an agent to maximize reward through trial and error in an environment, used in game-playing systems and robotics. Deep learning is a subset of machine learning using neural networks with many layers, enabling breakthroughs in vision, speech, and natural language. Common machine learning algorithms include linear regression, decision trees, random forests, support vector machines, k-nearest neighbors, and gradient boosting. Model evaluation uses held-out test sets to measure accuracy, precision, recall, or other task-specific metrics. Overfitting occurs when a model memorizes training data but fails to generalize; regularization, dropout, and cross-validation help prevent it. Machine learning powers recommendation systems, fraud detection, medical diagnosis, autonomous vehicles, and large language models.
